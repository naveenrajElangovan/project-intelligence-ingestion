# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`nae@tiendas3b.com` with:

- the affected repository, component, and version or commit;
- reproduction steps or a proof of concept;
- the expected impact and any known mitigations; and
- a secure way to contact you for follow-up.

The maintainers will acknowledge the report, coordinate validation and remediation,
and agree on disclosure timing with the reporter. Please keep details confidential
until a fix or mitigation is available and coordinated disclosure is approved.

## Supported versions

Security fixes are applied to the default branch. Release-specific support is
documented in the corresponding GitHub release notes.
